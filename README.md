## 🖼️ About

**ArtVista** is a premium art marketplace connecting art lovers with original paintings and curated art events. Built with a modern React frontend and a secure Spring Boot backend, it delivers a smooth shopping and event registration experience — complete with online payments, order tracking, and an admin management panel.

---

## ✨ Features

### 👤 For Users
- 🔐 Secure login & signup with JWT authentication
- 🖼️ Browse and search paintings filtered by artist
- 🎭 Explore and register for art events
- 🛒 Shopping cart with single and bulk purchase
- 💳 Online payment via **Cashfree** (Cards, UPI, Netbanking) or **Cash on Delivery**
- 📦 Track all orders and event registrations in one place
- 📬 Submit queries and complaints to support
- ⏱️ Auto-logout after inactivity with countdown warning

### 🛠️ For Admins
- 📊 Dashboard with real-time platform statistics
- 🎨 Manage artists — add, edit, delete with image upload
- 🖼️ Manage paintings — full CRUD with infinite scroll
- 🎭 Manage events — create events with seat capacity control
- 📦 Manage orders — view details, update delivery status
- 👥 Manage users — view and respond to user complaints

## 🔒 Security

- JWT-based authentication with role separation (User / Admin)
- All user-specific data endpoints protected against unauthorized access
- Auto-logout on token expiry and 30-minute inactivity
- Admin routes protected on both client and server
